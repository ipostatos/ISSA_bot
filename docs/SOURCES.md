# Источники банков вопросов

Этот файл заменяет прежнюю ссылку из README на `../_extracted/sources.txt` —
тот файл лежал **вне репозитория** и вместе с ним не распространялся, то есть
для любого, кто клонировал проект, ссылка была мёртвой.

Список ниже собран **из самого репозитория**: у каждого вопроса есть поле `ref`
с указанием источника, и цифры получены пересчётом этих полей, а не написаны
по памяти. Проверить можно в любой момент — поле видно в `questions.json`
и в польских банках, а в Mini App оно показывается под разбором ответа.

## Русский банк — откуда что

| Группа источников | Вопросов |
|---|---:|
| Учебные материалы курса ISSA (навигация, метеорология, приливы, якорная стоянка, швартовка, узлы, устройство яхты, безопасность, MOB, терминология) | 353 |

Все четыре группы — **открытые первоисточники и общепринятые морские правила**.
Экзаменационные ключи ISSA или какой-либо школы в проекте отсутствуют:
формулировки составлены и переработаны заново, ответы выведены из текста правил.

## Польские банки

`Żeglarz jachtowy` (150) и `Sternik motorowodny` (460) — вопросы государственных
экзаменов на польские патенты. Они **публикуются официально** и по своей природе
являются общедоступными: комиссия экзаменует строго по опубликованному набору.
В репозитории они хранятся в гибридном формате PL/RU «как на листе» — польская
формулировка не переводится, чтобы ученик видел ровно тот текст, который будет
на экзамене.

## Чего в проекте нет

- нет экзаменационных билетов ISSA и ответов к ним;
- нет материалов, полученных из закрытых или платных баз;
- нет копий чужих учебников (PDF-книги, если они лежат на сервере, в git
  **не входят** — см. `.gitignore`, раздел `webapp/books/`).
