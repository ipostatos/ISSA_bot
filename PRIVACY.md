# Политика конфиденциальности

Бот — учебный тренажёр для подготовки к ISSA Inshore Skipper + SRC.

## Какие данные обрабатываются

Бот хранит **минимум** данных, необходимых для работы тренировки:

- **Ваш Telegram ID** — чтобы вести прогресс отдельно для каждого пользователя.
- **Прогресс обучения**: какие вопросы вы видели, где ошибались, статистика
  ответов, серия решённых задач T-V-M-D-C, выбранный язык интерфейса.

Данные хранятся в файлах `progress/<ваш_id>.json` на сервере бота.

### Синхронизация между устройствами (если включена)

Mini App (приложение в Telegram) может синхронизировать прогресс между вашими
устройствами через серверный API. Если синхронизация активна, на сервере в
базе данных (SQLite) дополнительно хранится:

- **Telegram ID** — берётся только из подписанных Telegram данных (`initData`,
  проверка подписи HMAC-SHA256); никак иначе вас не идентифицируют.
- **Состояние обучения**: данные интервального повторения (по каким вопросам
  и когда показывать снова), дневная цель, серия, дни активности, прогресс
  по польским лицензиям (Żeglarz, Sternik).
- **История прохождений**: краткая запись о каждом тесте — режим, сколько
  вопросов, сколько верных, процент, длительность, время. Хранятся последние
  100 записей на пользователя.

Сервер видит **только обезличенный набор**: ваш Telegram ID и учебный прогресс.
Тексты ответов, переписка, контакты на сервер не передаются. Без включённой
синхронизации приложение работает полностью на вашем устройстве (localStorage),
ничего не отправляя.

### Что остаётся только на вашем устройстве

Сохранённые места в разделе «Погода», последнее выбранное место, настройки
(язык, голос озвучки, дата экзамена) и прогресс без синхронизации хранятся в
памяти браузера Telegram (localStorage) и на сервер не отправляются.

## Что НЕ собирается

- ❌ Имя, телефон, переписка, контакты.
- ❌ Геолокация на нашем сервере (о кнопке «Моё место» — ниже).
- ❌ Платёжные данные: оплату звёздами проводит Telegram, бот получает только
  факт оплаты и сумму, чтобы сказать «спасибо», и нигде их не сохраняет.
- ❌ Содержимое других чатов.

Бот работает **только в личном чате** и не читает сообщения в группах.

## Внешние сервисы

Некоторые разделы Mini App загружают данные напрямую со сторонних сервисов.
Ваш Telegram ID и прогресс им не передаются, но, как при открытии любой
веб-страницы, сервис видит IP-адрес вашего устройства и сам запрос.

| Сервис | Где используется | Что получает |
|---|---|---|
| Telegram (`telegram.org`) | все страницы Mini App | загрузку скрипта Telegram Web App |
| Open-Meteo (`open-meteo.com`) | «Погода»: прогноз, волны, поиск места | название места из поиска или координаты места |
| Esri (`arcgisonline.com`) | «Погода»: подложка карты ветра | какой участок карты вы смотрите |
| Городская камера Гданьска (`kamera.task.gda.pl`) | «Веб-камеры» | запрос видеопотока, пока вы его смотрите |
| Buy Me a Coffee | «О проекте», кнопка поддержки | открывается только по вашему нажатию |

**Геолокация.** Кнопка «Моё место» в разделе «Погода» спрашивает разрешение
устройства и только после вашего согласия берёт координаты. Они уходят
напрямую в Open-Meteo, чтобы получить прогноз для этой точки. На наш сервер
координаты не отправляются. Без нажатия кнопки геолокация не запрашивается.

## Хранение и удаление

- Данные хранятся, пока вы пользуетесь ботом.
- Кнопка **«♻️ Сбросить прогресс»** в меню удаляет вашу статистику в боте.
- При перезапуске бота сохранённый прогресс не теряется; сбрасываются только
  незавершённые в этот момент экзамены/задачи.
- Серверная история синхронизации хранит последние 100 прохождений на
  пользователя (старые вытесняются автоматически). Чтобы удалить данные
  синхронизации полностью — напишите владельцу (см. ниже).
- **Резервные копии.** Раз в сутки сервер делает резервную копию базы
  синхронизации и файлов прогресса бота. Копии лежат на том же сервере,
  закрыты от посторонних и хранятся **14 дней**, после чего удаляются
  автоматически. Поэтому удалённые данные полностью исчезают из копий не
  позже чем через 14 дней.
- **Технические журналы.** Журнал работы сервера может содержать Telegram ID
  в служебных записях (например, об ошибке). Его объём ограничен, старые
  записи стираются автоматически, обычно через две–три недели.

## Передача третьим лицам

Ваш Telegram ID и прогресс **не передаются** третьим лицам и используются
только для работы тренажёра. Какие внешние сервисы видят запросы из
Mini App и что именно они получают — в разделе «Внешние сервисы».

## Контакт

Вопросы по приватности — через владельца бота (см. профиль в Telegram).
